Higher Order Factorial Designs

Higher Order Factorial Design

Conceptually there is nothing that limits us to CR[1] and CR[2]. Can do CR[3], CR[4], …

  • In social sciences, higher order designs are less common > small effect sizes and high measurement error means we need to use lots of data to get high power.
  • In natural sciences, high order designs are more common > larger effect sizes and low measurement error means we can detect effects with less data.

Two-way Interaction Plots

You’ll need at least one interaction plot for each pairwise combination of factors (1 for CR[2], 3 for CR[3]).

  • Calculate the mean response over every treatment combination of the two factors.
  • Plot those means on the y axis, with the first factor on the x and the second factor differentiated by color, linetype or shape.
  • Draw lines between the means with the same level of the second factor.

Parallel lines indicate no interaction.

3-way Interaction Plots

You’ll need at least one interaction plot for each pairwise combination level of one of the three factors.

  • Filter the data for just one level of the first factor.
  • Calculate the mean response over every treatment combination of the two factors.
  • Plot those means on the y axis, with the first factor on the x and the second factor differentiated by color, linetype or shape.
  • Label the plot with the level of the third factor.
  • Draw lines between the means with the same level of the second factor.

Randomization-based Inference

Recall for 2 factor w interactions:

shuffle_two_factor <- function(y, a, b) {
  Y <- sample(y) # source of randomness

  battery_sim <- data.frame(lifetime = Y,
                            temp = a,
                            material = b)
  
  battery_anova <- aov(lifetime ~ temp * material, data = battery_sim)
  anova_table <- summary(battery_anova)
  f_stats <- anova_table[[1]]$`F value`
  f_stats
}
null_stats <- replicate(500, shuffle_two_factor(y = battery$lifetime,
