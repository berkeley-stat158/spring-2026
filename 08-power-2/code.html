In a world where…

To toy around with the notion of statistical power, let’s start by creating a toy schedule of potential outcomes for 10 units. I’ll start with only the potential outcomes under the control.

my_true_sched <- tibble(Y_0 = c(-.1, -.5, 1.2, -1.4, .1, -1, 1.1, 0, .02, .5))

To populate the second potential outcome, let’s work with a very particular assumption about the causal mechanism: that the ITE (and thus the ATE) is 1 for all units.

tau <- 1
my_true_sched <- my_true_sched |>
  mutate(Y_1 = Y_0 + tau)

Find Sampling Distribution under \(H_0\)

First let’s load our workhorse function for doing randomization based inference.

rand_stats <- function(schedule, d_i, stat = "diff in means", reps = 1000) {

  # store treatment vector separately
  d_i_vec <- d_i

  # replicate the schedule reps times and stack them on top of one another
  randomized_exp_df <- map_dfr(1:reps, ~ schedule, .id = "experiment") |>
    mutate(experiment = factor(experiment, levels = as.character(1:reps), ordered = TRUE),
           d_i = c(replicate(n = reps, sample(d_i_vec))),  # create random assignments
           y_i = Y_1 * d_i +  Y_0 * (1 - d_i)) |>    # find observed responses
    arrange(experiment)

  # calculate test statistic for every random assignment
  if (stat == "diff in means") {
    stats <- randomized_exp_df |>
      group_by(experiment, d_i) |>
      summarize(ybar = mean(y_i),     # average within each group within each experiment
                .groups = "drop_last") |> 
      summarize(ATE_hat = diff(ybar),
                .groups = "drop") |>   # take the difference between the two groups mean 
      pull()
  } else {
    stop("Statistic not implemented")
  }

  return(stats)
}
H_0 <- rand_stats(schedule = my_null_sched, d_i = d_i, reps = 5000)
p_val <- mean(abs(H_0) > ATE_obs)

p_val
[1] 0.0222

Visualizing the threshold

In a two-tailed test at \(\alpha = .05\), the rejection region is anything less than the .025 quantile and anything more than the .0975 quantile of the null distribution of statistics.

left_threshold <- quantile(H_0, .025)
right_threshold <- quantile(H_0, .975)
data.frame(stat = H_0) |>
  ggplot(aes(x = stat)) +
  geom_histogram() +
  geom_vline(xintercept = c(left_threshold, right_threshold), col = "tomato") +
  theme_bw()
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.

Find Sampling Distribution under \(H_A\)

The only thing that changes to find the sampling distribution under \(H_A\) is the schedule.

H_A <- rand_stats(schedule = my_true_sched, d_i = d_i, reps = 5000)

We can now visualize these side-by-side.

data.frame(stat = c(H_0, H_A),
           type = factor(c(rep("Null", length(H_0)),
                           rep("Alt", length(H_A))))) |>
  ggplot(aes(x = stat, fill = type)) +
  geom_histogram(position = "identity", alpha = .3) +
  geom_vline(xintercept = c(left_threshold, right_threshold), col = "tomato") +
  theme_bw()

Calculate Power

Let’s calculate the power.

power <- mean(H_A > right_threshold | H_A < left_threshold)
power
[1] 0.2366

Let’s combine this into one informative plot.

data.frame(stat = c(H_0, H_A),
           type = factor(c(rep("Null", length(H_0)),
                           rep("Alt", length(H_A))))) |>
  mutate(in_reject_region = ifelse(stat > right_threshold | stat < left_threshold, "Reject Null", NA)) |>
  ggplot(aes(x = stat, fill = type, color = in_reject_region)) +
  geom_histogram(position = "identity", alpha = .3) +
  geom_vline(xintercept = c(left_threshold, right_threshold), col = "tomato") +
  scale_color_manual(
    values = c("Reject Null" = "black"),
    na.value = NA,
    guide = "none") +
  labs(title = paste0("Statistical Power: ", round(power, 2)),
       subtitle = paste0("n0 = ", n_0, ", n1 = ", n_1, ", tau = ", tau)) +
  theme_bw()
